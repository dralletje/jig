# The `fs` Image Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new image, `localhost/jig/fs:local`, that copies, moves, removes, unwraps and wraps files and folders and reports on the minimal report v1.

**Architecture:** busybox plus the static Nushell 0.117.0 binary and one script, `containers/fs/fs.nu`. The script parses its own arguments, checks everything before touching a file, does the work with nu's `cp`/`mv`/`rm`, and prints one report line. It is tested only end to end through the jig binary, in `swift/cli`'s `IntegrationTests`.

**Tech Stack:** Nushell 0.117.0 (musl static build), busybox, Docker; Swift 6.4.2 swift-testing for the tests.

**Spec:** `docs/superpowers/specs/2026-11-20-fs-image-design.md`

## Global Constraints

- Report: success is exactly `{"schema":"urn:jig:report:1","ok":true,"kind":"rewrite","subject":…,"summary":…}` with exit 0; failure is exactly `{"schema":"urn:jig:report:1","ok":false,"code":…,"instructions":…}` with exit 1. It goes on the last line of stdout, as compact JSON (`to json --raw`).
- `kind` is `rewrite` for every command. `subject` is `rewrite(<command>): <what>`, one line.
- Codes: an unknown or missing command is `UNKNOWN_ACTION`. Bad flags, a bad path, a missing source, a destination that is not free and a collision are `INVALID_ARGS`. Nothing to do is `NO_CHANGES`.
- Every check runs before anything is touched: a refusal leaves `/workspace` exactly as it was.
- Paths are relative to `/workspace` (the repo root). Refused: absolute, empty, `.` (the root), any `..` part, any `.git` part, and any path whose parent folders include a symlink. A leading `./` and a trailing `/` are accepted and dropped. The normalized form is what appears in subjects, summaries and instructions.
- "Free" means nothing exists at the path: no file, folder or symlink, a dangling one included (test with `path type`, which does not follow links, not `path exists`).
- File counts in summaries count files and symlinks (not folders), with `1 file` / `N files`.
- The `remove --files` list is formatted like `listLines` in `packages/core/src/report.ts`: each item on its own line indented two spaces, at most 20, then `  … and N more`.
- The entrypoint is `def --wrapped main [...args: string]` with hand parsing, so nu's own flag errors never replace the JSON report. An unexpected nu error is caught and reported as `INTERNAL` (jig turns that into `IMAGE_FAILED`).
- The Containerfile pins `busybox` to an exact version tag and checks the nu release archive against its SHA-256, for amd64 and arm64 (`TARGETARCH`).
- Repo style: inline strings over constants, explicit over DRY. Read and write files with the Read, Write and Edit tools; run shell commands through `nux`. Build images with `sh scripts/build-images.sh fs`; run the end-to-end suite with the swift path from `scripts/test-swift.sh`, e.g. `swift test --filter FsTests` in `swift/cli`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Dotfiles.** `unwrap`, `copy`, `move` and `wrap` must carry `.hidden` files along (nu's `ls` and `glob` skip them unless asked), and `remove --files "**/.DS_Store"` must match them. Tests in Tasks 1 and 2.
2. **Names with spaces and non-ASCII.** `copy --from "my dir" --to "été"` works and the subject shows the names as given. Test in Task 1.
3. **`./src/old/` style paths.** Normalized to `src/old`, not refused and not doubled in the subject. Test in Task 1.
4. **Symlinks.** A copied symlink stays a symlink with the same target; a dangling symlink at the destination makes it not free; `remove --paths link` removes the link, not its target; a path through a symlinked folder is refused. Tests in Tasks 1 and 2.
5. **The executable bit.** `copy` and `move` keep it (git records it). Test in Task 1.
