# Off Bun Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nothing in jig needs Bun. The action images run on Node 26, the package unit tests use `node:test`, and the end-to-end tests are Swift.

**Architecture:** The action packages run as TypeScript source under Node 26's type stripping. Images install their dependencies with npm at build time. The end-to-end suite becomes a swift-testing integration target in `host/` that drives the built binary.

**Tech Stack:** Node 26.13.1 (`node:26.13.1-slim`), `node:test`, npm (inside the images), pnpm (host dev), Swift 6.4.2 with swift-testing, docker, git, POSIX sh.

**Spec:** `docs/superpowers/specs/2026-11-18-no-bun-design.md`. The image contract is in `docs/superpowers/specs/2026-11-17-container-actions-design.md`; the host binary in `docs/superpowers/specs/2026-11-17-swift-host-design.md`.

## Global Constraints

- No Bun anywhere when done: no `bun` commands, `Bun.*` APIs, `bun:` imports, `bun-types`, `bun.lock` or `bunfig.toml`, and no Bun in docs except AGENTS.md's "do not reintroduce it".
- **Node:** 26.13.1. Images use `FROM node:26.13.1-slim`. Locally it is at `~/.local/share/node/node-v26.13.1-linux-x64/bin` (not on PATH). Scripts find it via `$NODE`, then `node` on PATH if its version starts with `v26.`, then that path.
- **Swift:** 6.4.2 at `~/.local/share/swiftly/toolchains/6.4.2/usr/bin` (not on PATH).
- **TypeScript source rules:** only erasable syntax, `.ts` import extensions, `import type`. Packages keep `"exports": { ".": "./src/index.ts" }`.
- **Image contract, CLI, binary behaviour:** unchanged. Image tags stay `localhost/jig/{typescript,prettier}:local`. Entrypoints are `["node", "/app/packages/<pkg>/src/bin.ts"]`, which must work under `docker run --rm --network none --read-only --tmpfs /tmp`.
- **Processes:** every one runs with an argument array, never through a shell. Shell scripts are POSIX `sh` and pass `shellcheck`.
- **Symlinks:** AGENTS.md's symlink rule applies. Do not add rules about symlinks created by images, and do not raise it.
- **Verification:** every task ends with `pnpm typecheck` (exit 0) and the package unit tests on Node 26 (all pass). From Task 2 on, it also ends with `swift test` in `host/` (all pass, integration tests included).

## Review Focus

1. **Node refuses to strip types under `node_modules`.** Inside both images, `@jig/core` must load from `/app/packages/core/src`. The smoke runs prove it (Task 1).
2. **A repo whose JS prettier config imports a missing package** must still fall back to prettier's defaults under Node (`--network none`, nothing auto-installed). Keep the existing test (Task 1).
3. **Glob semantics change** from `Bun.Glob` to `path.matchesGlob`: `src/**`, `**/*.ts` and comma-separated lists must match the same tracked files as before. Unit test (Task 1).
4. **Node startup inside a read-only container:** no writes outside `/tmp` and `/workspace` (npm and Node caches). The smoke run uses `--read-only` (Task 1).
5. **The Swift integration tests** must skip, not fail, when docker is unavailable, and must clean up their temp repos (Task 2).
